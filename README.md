# Сайт Модели ООН ННГУ (LSU MUN)

Обычные HTML/CSS/JS-страницы, без сборки: можно положить на GitHub Pages или любой хостинг.

- `index.html` — главная, `committees.html` — комитеты, `team.html` — президиум, `archive.html` — архив по годам, `cabinet.html` — личный кабинет.
- Всё содержимое (комитеты, председатели, приветствия, сессии, призёры) — в `js/data.js`. Тексты интерфейса RU/EN — в `js/i18n.js`.
- Английская версия: кнопка RU/EN или `?lang=en` в адресе.
- Приветствия гостей: в `js/data.js` → `greetings` вписать `photo: "img/....jpg"` и `quote: { ru, en }`.
- Новая сессия: добавить её в начало `sessions`, комитеты — в `committees`, поправить `next`.
- Личный кабинет сейчас работает в демо-режиме (данные хранятся в браузере). Для настоящего входа нужен сервер: функции `store.load/save` в `js/cabinet.js` заменить на запросы к API.
- Фото взяты из группы vk.com/lsumun.

Локальный просмотр: `python3 -m http.server 8765` в этой папке → http://localhost:8765
